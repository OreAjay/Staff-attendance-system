# Staff Attendance Management System

## Overview
A web-based staff attendance system developed using Python, Flask, and SQLite. It records staff clock-in and clock-out activities and provides attendance reports.

## Features
- Staff registration
- Staff directory
- Clock-in and clock-out recording
- Validation to prevent duplicate clock-ins and invalid clock-outs
- Individual staff attendance records
- Daily attendance report
- SQLite database storage

## Technologies Used
- Python
- Flask
- SQLite
- HTML and CSS

## How to Run
1. Open the project folder in Visual Studio Code.
2. Open the terminal.
3. Activate the virtual environment if necessary.
4. Run `python app.py`.
5. Open `http://127.0.0.1:5000/` in a browser.

## Database
The system stores staff details and attendance records in `attendance.db`.
